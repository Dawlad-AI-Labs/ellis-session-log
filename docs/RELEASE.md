# v0.1.0 release decision

Scope: one unchanged Ellis session-log module, synthetic example, tests and documentation. Destination: Dawlad-AI-Labs/ellis-session-log, public. Tag: v0.1.0 (the earlier private candidate commit 9b56da43 carried this tag before release; it was never public, and the tag was moved once to this release-documentation commit before visibility changed).

Public About: Dependency-free Node.js JSONL session logging extracted from the Ellis prototype, with synthetic examples and restart tests.
Topics: nodejs, jsonl, session-logging, reference-implementation.

Release approval: Aly Solamon (rights holder) asked on 26 November 2026 for this to be published as Dawlad's first open-source reference, under MIT with copyright Aly Solamon. No public announcement is part of this release; announcement and full Ellis deployment are separate decisions.

Maintainer: Noor. After release: verify remote visibility, tag commit and a clean public clone before reporting public acceptance. Do not move a published tag. Support status: research reference; next review 26 February 2027.

No full-app, voice-provider, browser or learning-outcome verification is included. This reference is useful for inspecting file-based logging, not a substitute for the professor-practice deployment milestone.
